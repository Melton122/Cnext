# Plan: Add All Built-in Functions as Global (No Import Required)

## Summary

Make all listed functions available globally without requiring `import` statements. Currently many exist via module imports (e.g., `import string_utils` for `str_trim`), but the user wants them all as builtins.

## Architecture Overview

The compiler has a 3-layer pattern for built-in functions:
1. **Semantic analyzer** (`src/semantics_types.c`): Registers function names in the symbol table so they resolve
2. **Code generator** (`src/codegen_expr.c`): Recognizes function names and emits C code
3. **Runtime** (`include/runtime.h`): C implementations that get compiled into the output

Then replace the big if/else chain with a loop:

```c
// In the AST_CALL handler, after the class method dispatch:
bool found_builtin = false;
for (int b = 0; builtin_table[b].name; b++) {
    if (node->left->token.length == (int)strlen(builtin_table[b].name) &&
        strncmp(node->left->token.start, builtin_table[b].name, node->left->token.length) == 0) {
        fprintf(out, "%s", builtin_table[b].c_emit);
        for (int i = 0; i < node->child_count; i++) {
            generate_expression(node->children[i]);
            if (i < node->child_count - 1) fprintf(out, ", ");
        }
        fprintf(out, ")");
        found_builtin = true;
        break;
    }
}
```

Special cases (printin, print, input, len) keep their existing individual handling since they have complex codegen logic.
