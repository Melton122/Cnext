2. Installing Cnext

BEGINNER

2.1 What You Need

Because Cnext generates C, you need two things:

  1. The Cnext compiler itself.
  2. A C compiler (GCC or Clang) to turn the generated C into an executable.
Note On Windows, install GCC via MSYS2 (MinGW64). On Linux, install build-essential. On macOS, install Xcode Command Line Tools (xcode-select --install).

2.2 Installing Cnext

Windows (one command, in PowerShell)

irm https://install.cnext.dev/install.ps1 | iex

Linux / macOS (one command)

curl -fsSL https://install.cnext.dev/install.sh | sh

Build from Source

Clone the repository and build with make:

git clone https://github.com/Melton122/cnext.git
cd cnext
make
sudo make install
Tip Building from source is ideal if you want to contribute to the compiler itself. Plain make produces an optimized release build; make DEBUG=1 builds with debug symbols.

2.3 Verify It Works

cnext version
cnext doctor

cnext version prints the compiler version. cnext doctor inspects your environment and reports whether the C compiler and other tools it needs are present — a handy first health check.

2.4 Troubleshooting

SymptomLikely causeFix
command not found: cnextCompiler not on PATHAdd the install folder to your PATH, or re-run the installer.
fatal error: runtime.h: No such file or directoryC cannot find Cnext’s runtime headersReinstall so headers land in the standard location, or rebuild.
gcc: not foundNo C compiler installedInstall GCC/Clang (build-essential / MSYS2 / Xcode tools).
Key point The two-line mental model: cnext translates your code to C, and a C compiler finishes the job. If either piece is missing, your program cannot run.
