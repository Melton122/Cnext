4. The Basics: Comments, Variables, Input & Output

BEGINNER

Every program is built from a small set of ideas: named containers (variables), ways to put data in and get data out (input/output), and rules for structuring files (comments, blocks). This chapter covers them all.

4.1 Comments

Comments are notes for humans. The compiler discards them.

// This is a single-line comment.

/* This is a
   multi-line comment. */
main {
    // printin("this is commented out and will not run")
    printin("this runs")
}
Tip Comments explain why, not what. Good code is often self-explanatory; comments shine when they capture intent ("we clamp here so the value never exceeds 100") or non-obvious trade-offs.

4.2 Variables

A variable is a named box that holds a value. You can declare it with an explicit type or let the compiler infer the type with var. 

int score = 90            // explicit type: 32-bit whole number
var name = "Ada"          // inferred type: str
var pi = 3.14             // inferred: float
var passed = true         // inferred: bool
score = 95                // values can change later
Key point var x = value lets Cnext figure out the type for you (type inference). It is still statically typed: the type is fixed at compile time, so you can’t later store a string in a variable that was created as an integer.

4.3 Constants

When a value should never change, declare it with const:

const int MAX_RETRIES = 3
const str APP_NAME = "Notes"
// MAX_RETRIES = 5   // compile error: cannot reassign a constant

4.4 Blocks & Scope

Every { ... } opens a new scope. A variable declared inside a block exists only until the block ends. 

main {
    var outside = 10
    if true {
        var inside = 20   // exists only in this block
        printin(outside)  // ok: outside is visible here
    }
    // printin(inside)    // error: `inside` is gone
}

4.5 Printing Output

Use print (no new line) and printin (prints a new line after).

printin("line 1")
printin("line 2")
print("no newline here -> ")
printin("continues on same line")

Output:

line 1
line 2
no newline here -> continues on same line

4.6 Reading Input

Ask the user for text with input:

main {
    print("Enter your name: ")
    var name = input()
    printin("Hello, " + name + "!")
}
Real world Separating input, processing, and output is the oldest software pattern. Programs like a grade calculator read data, compute, and write results — exactly what this tiny greeting program does with text.
Exercise 4.1 Write a program that asks for a user's name and favorite number, then prints a sentence such as Hello, Ada! 7 is a great choice. Use variables and string concatenation.
Suggested solution 
main {
    print("Name: ")
    var name = input()
    print("Favorite number: ")
    var num = input()
    printin("Hello, " + name + "! " + num + " is a great choice.")
}
