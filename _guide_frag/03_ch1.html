1. What Is Cnext? (and Why C?)

BEGINNER

1.1 Computers Speak Machine Code

When you want a computer to do something, you must communicate in a form it can execute. At the very bottom, a CPU understands only small, primitive instructions — move this number into that register, compare two values, jump to another place in the program. These are called machine code, and they differ between processor families.

Theory — high-level vs. low-level languages A high-level language (Python, JavaScript, Cnext) is written in words and symbols close to how people think: if x > 0. A low-level language (assembly, machine code) is written in the exact, tiny steps a processor executes. High-level languages are easier and safer to write; the trade-off is that some translator — a compiler — must turn them into machine code for you.

1.2 What Cnext Is

Cnext is a statically typed, compiled language with a syntax many describe as "a friendlier C." Rather than compiling all the way to machine code in one step, Cnext compiles your program to portable C source, which a standard C compiler (GCC or Clang) turns into a native executable.

1.3 How Cnext Works

Follow the journey of a file:

your_program.cn --(cnext build)--> C source --(gcc/clang)--> your_program
  1. Lexing — your text becomes meaningful tokens (main, {, printin, ...).
  2. Parsing — tokens are assembled into a tree matching the language’s grammar.
  3. Semantic analysis — the compiler checks types match, names exist, and rules are respected.
  4. Code generation — the validated tree is turned into C source.
  5. Native compilation — GCC/Clang build a native executable for your machine.
Key point "Cnext" means C NEXT: modern syntax on top of C’s proven, portable, and fast runtime. The generated output is ordinary C understood by any mainstream toolchain.

1.4 Why Build on C?

C has written operating systems, databases, game engines, and much of the world’s infrastructure. By generating C, Cnext inherits three things automatically:

  • Portability — any platform with a C compiler can run Cnext programs.
  • Performance — near-native speed without hand-writing assembly.
  • Interop — Cnext programs can call the enormous universe of C libraries.

1.5 What Cnext Looks Like

Here is a complete program you will dissect in Chapter 3:

func greet(str name): str {
    return "Hello, " + name + "!"
}

main {
    printin(greet("World"))
}

Notice there is little ceremony: func declares a function, the return type follows a colon, and main is the entry point. Semicolons are optional.

Real world The same pipeline you are learning here powers the Linux kernel, Python, and Git. Understanding "source → C → executable" is a skill you will reuse for the rest of your career.
